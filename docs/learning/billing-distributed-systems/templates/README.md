# Reasoning Toolbox

These templates are optional tools. Use one only when its result will help the current investigation or retain knowledge with future value. They are not required for progress, and partial use is welcome.

| When you need to… | Useful tool |
|---|---|
| sketch actors, state, boundaries, or failure windows | [Mental model](mental-model.md) |
| preserve a meaningful prediction before an experiment | [Prediction log](prediction-log.md) |
| make one experiment repeatable or capture a subtle result | [Experiment report](experiment-report.md) |
| compare failures and recovery behavior across several boundaries | [Failure matrix](failure-matrix.md) |
| reason through a production guarantee before implementation | [Design proposal](design-proposal.md) |
| consolidate or transfer an idea after substantial work | [Teach-back](teach-back.md) |

Copy only the useful sections, write rough notes directly in a session, or ignore the templates entirely. The criterion is future utility—not evidence that learning occurred.
